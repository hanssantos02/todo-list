# Ledger
<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
People managing personal tasks and projects locally, using keyboard, mouse, or touch. The release is also intended for demonstration to engineers, designers, and potential employers.

## Product Purpose
A calm personal productivity workspace: capture immediately, see what matters today, organize tasks into projects, and understand progress without pressure.

## Operating Context
A local-first browser application with no accounts or backend. The same work must remain usable on desktop, tablet, and mobile.

## Capabilities and Constraints
Preserve vanilla JavaScript ES modules, Webpack, date-fns, existing project/task IDs, project.todos arrays, and the todo-projects localStorage key. Ship full editing, smart views, combined search/filter/sort, project management, reversible destructive actions, theme preferences, keyboard shortcuts, and validated JSON backup/restore. The user confirmed Daily Brief, seven-day overview, and lightweight Focus Mode. Subtasks, recurrence, reminders, drag-and-drop, and PWA work are deferred. No publishing or PR without explicit authorization.

## Brand Commitments
Ledger — a quiet todo. Preserve its warm paper, ink, moss, serif editorial identity. Voice is direct, quiet, and useful. Do not fabricate tasks, historical statistics, or claims.

## Product Principles
- Capture with a title; disclose optional detail when needed.
- Derived views never duplicate persisted tasks.
- Protect existing data before improving presentation.
- Keep keyboard and pointer workflows equally usable.
- Progress provides context without scoring or pressure.

## Accessibility & Inclusion
Target WCAG 2.2 AA; semantic native controls, keyboard dialogs, focus restoration, readable contrast, touch targets, live feedback, and reduced motion.

## Evidence on Hand
The user's Ledger 2.0 brief and existing src implementation. No production user research or historical completion data is available.
