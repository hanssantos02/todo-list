# Ledger workspace

Mode: Operate.

Job: capture and organize personal work, identify due and overdue tasks, and complete or revise entries without losing context.

First viewport: a persistent paper index at left; date and local-storage context across the top; a large serif destination title; a concise actual-data daily brief; seven-day workload strip in Today/Upcoming; title-first capture; and a ruled task list. Empty Ledger begins honestly empty, with a direct capture action. No synthetic tasks ship.

Hierarchy: destination → summary → capture → entries. Filters disclose below the search/sort toolbar. Project counts indicate remaining work. Task rows retain project, due date, priority, notes disclosure, edit, and Focus affordances. Protected edits use a native dialog so Cancel can discard a draft atomically.

Responsive: below 720px, the persistent index becomes a modal navigation drawer. Main content uses one column; form fields and filter controls wrap, task actions occupy a second row, and capture stays directly above results. At tablet size retain navigation with a narrower gutter. Long titles wrap instead of clipping. No permanent third column.

Quality bar: editorial hierarchy without dashboard cards, keyboard and touch parity, accessible contrast in both themes, visible focus, honest storage status, and safe legacy recovery. Verify desktop 1440, tablet 768, mobile 375, and the in-app browser width in two bounded rounds.

Selected additions: Daily Brief uses current due/overdue/completed counts, without inventing completion history; weekly strip reveals a selected local date; Focus Mode shows one real task and its notes with complete and exit actions. Defer subtasks and recurrence because their semantics and persistent model add risk without improving the core release.

## Direction contract

THESIS: A working ledger whose next entry is always within reach; use a ruled task list rather than a wall of dashboard cards.

OWN-WORLD: Warm paper and quiet ink, moss actions, Spectral headings, native forms, thin rules, and one shared control grammar across both themes.

STORY: See what needs attention, capture a thought, revise it safely, and close an entry with a recoverable action.

FIRST VIEWPORT: A 224–256px persistent index, date strip, large serif destination, concise daily counts, seven-day strip, title-first capture, then grouped ruled entries. Phone replaces the index with a modal drawer.

FORM: Precisely specified extension of the user's existing editorial workspace; concept seed is not applicable because the user pinned the world and layout regions. Code-first was explicitly confirmed.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
